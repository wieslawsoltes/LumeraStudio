# Design and technical references

These public primary sources informed the workflow research. No proprietary code or assets were copied into Lumera.

- [Foundry Katana product overview](https://www.foundry.com/products/katana)
- [Katana user guide](https://learn.foundry.com/katana/Content/user_guide.html)
- [Node graph and scene graph quick start](https://learn.foundry.com/katana/3.0/Content/ug/creating_project/quick_start_guide.html)
- [GafferThree light workflow](https://learn.foundry.com/katana/Content/rg/misc_nodes/gafferthree.html)
- [Katana rendering architecture](https://learn.foundry.com/katana/Content/ug/rendering_scene/rendering_scene.html)
- [WGSL language and buffer layout specification](https://www.w3.org/TR/WGSL/)
- [GPUDevice API](https://gpuweb.github.io/types/interfaces/GPUDevice.html)

Lumera's collaboration service is an additional original implementation. The reference research did not establish live shared-cursor editing as a Katana feature. Likewise, a new WebGPU renderer is not a port of Katana's plug-in renderers.
